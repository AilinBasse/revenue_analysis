This project is built on a local analytics stack — MySQL running in Docker, queried and visualised through Metabase, and exposed via ngrok so the dashboards embed live in this page. The dataset models a B2B SaaS company's revenue across customers, regions, industries, products, and sales reps. Each section below pairs a live Metabase chart with the SQL behind it and a short note on what the data is telling us.

SELECT c.id, c.name,
       COUNT(o.id)   AS order_count,
       SUM(o.amount) AS lifetime_value
FROM customers c
JOIN orders o ON o.customer_id = c.id
WHERE o.status = 'completed'
GROUP BY c.id, c.name
HAVING order_count > 1
ORDER BY lifetime_value DESC;
